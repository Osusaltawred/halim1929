# أرشيف عبدالحليم حافظ الرقمي
## Abdel Halim Hafez Digital Archive

أرشيف رقمي شامل يوثق أعمال عبدالحليم حافظ: الأغاني، الحفلات، الأفلام، التسجيلات، الصور، والسيرة الذاتية.

مشروع Static يعمل مباشرة على GitHub Pages بدون Backend أو Server أو Database.

---

## التقنية المستخدمة

- HTML5
- CSS3
- JavaScript Vanilla (بدون أي Framework)
- LocalStorage (للمفضلة، آخر الاستماع، تفضيلات الوضع الليلي)
- PWA (Progressive Web App)
- Media Session API (لتشغيل الصوت في الخلفية)

## كيف أرفع المشروع إلى GitHub

1. أنشئ حساب على [GitHub](https://github.com) إن لم يكن لديك.
2. اضغط على **New repository**.
3. سمّ المستودع (مثلاً: `abdelhalim-archive`).
4. اختر **Public**.
5. لا تختر "Add README".
6. اضغط **Create repository**.
7. ارفع الملفات بإحدى طريقتين:

### الطريقة الأولى: عبر المتصفح
- اضغط **uploading an existing file**
- اسحب وأفلت جميع ملفات المشروع
- اضغط **Commit changes**

### الطريقة الثانية: عبر Git (للمتقدمين)
```bash
git clone https://github.com/USERNAME/abdelhalim-archive.git
cd abdelhalim-archive
# انسخ ملفات المشروع هنا
git add .
git commit -m "أرشيف عبدالحليم حافظ"
git push
```

## كيف أفعّل GitHub Pages

1. افتح المستودع على GitHub.
2. اذهب إلى **Settings**.
3. في القائمة الجانبية، اختر **Pages**.
4. في قسم **Source**، اختر:
   - **Branch:** `main` (أو `master`)
   - **Folder:** `/ (root)`
5. اضغط **Save**.
6. انتظر دقيقة أو دقيقتين.
7. سيظهر رابط الموقع في أعلى الصفحة، مثلاً:
   ```
   https://USERNAME.github.io/abdelhalim-archive/
   ```

## كيف أضيف صورة عبدالحليم كـ Favicon

1. ضع صورة عبدالحليم في مجلد `assets/` باسم `favicon.png`.
2. يُفضّل أن تكون الصورة مربعة (مثلاً 32x32 أو 64x64 بكسل).
3. كذلك ضع نسخة أكبر باسم `icon-192.png` (192x192) و `icon-512.png` (512x512) لأيقونة PWA.
4. إذا لم تضع صورة، سيظهر placeholder أنيق تلقائيًا.

**ملاحظة عن حقوق الصور:** لا تستخدم صورة لا تملك حقوق استخدامها. إذا لم تكن متأكدًا من حقوق الصورة، استخدم placeholder أو صورة من المصادر العامة.

## كيف أضيف الأغاني والصور والأفلام والحفلات مستقبلًا

### عبر لوحة الإدارة (الأسهل)

1. اذهب إلى: `https://USERNAME.github.io/abdelhalim-archive/admin.html`
2. كلمة المرور الافتراضية: `admin123`
3. استخدم التبويبات لإضافة:
   - **الأغاني:** اسم، سنة، ملحن، شاعر، فيلم، تصنيف، رابط صوتي
   - **الأفلام:** اسم، سنة، بطولة، مخرج
   - **الحفلات:** اسم، مدينة، دولة، سنة، مكان
   - **الملحنون:** اسم، نبذة
   - **الشعراء:** اسم، نبذة
   - **التصنيفات:** اسم التصنيف
   - **الصور:** عنوان، سنة، تصنيف، رابط/ملف

### لتثبيت البيانات بشكل دائم

1. في لوحة الإدارة، اضغط **تصدير JSON**.
2. سيتم تنزيل ملف `abdelhalim-archive-data.json`.
3. انسخ محتوى الملف.
4. استبدل محتوى `data.js` بالبيانات الجديدة (مع الحفاظ على بنية `ARCHIVE_DATA`).
5. ارفع الملف المحدّث إلى GitHub.

أو استخدم **نسخ البيانات** لنسخ JSON مباشرة إلى الحافظة.

## كيف أضيف ملفًا صوتيًا

### الطريقة الأولى: رابط خارجي (موصى بها)
1. في لوحة الإدارة، اذهب إلى تبويب الأغاني.
2. في حقل **رابط الصوت (Audio URL)**، ضع الرابط المباشر للملف الصوتي.
3. يجب أن يكون الرابط مباشرًا (ينتهي بـ .mp3 أو .ogg أو .m4a إلخ).

### الطريقة الثانية: ملف في المشروع
1. ضع الملف الصوتي في مجلد `audio/`.
2. في لوحة الإدارة، استخدم **Choose Audio File** لاختيار الملف.
3. أو اكتب المسار يدويًا: `audio/song-name.mp3`.
4. ارفع الملف إلى GitHub مع باقي الملفات.

**النظام يدعم:** MP3, WAV, OGG, M4A, AAC, FLAC، وأي صيغة يدعمها المتصفح.

**إذا لم يدعم المتصفح الصيغة:** لن تنهار الصفحة. سيظهر اسم الملف وحجمه ونوعه مع رسالة تنبيه.

## كيف أغير كلمة مرور Admin

كلمة المرور الافتراضية: `admin123`

لتغييرها:
1. افتح ملف `admin.js`.
2. ابحث عن `DEFAULT_PASSWORD`.
3. غيّر القيمة إلى كلمة المرور الجديدة.
4. ارفع الملف إلى GitHub.

**تنبيه:** هذه الحماية للأغراض التشغيلية فقط وليست أمانًا حقيقيًا، لأن الموقع Static وكل الكود مرئي للمستخدم.

## كيف أضيف تصنيفًا جديدًا

1. في لوحة الإدارة، اذهب إلى تبويب **التصنيفات**.
2. أدخل اسم التصنيف الجديد.
3. اضغط **إضافة**.
4. التصنيف الجديد سيظهر في قائمة التصنيفات عند إضافة الأغاني.
